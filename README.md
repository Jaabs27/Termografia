Análise termográfica FLIR

Página que lê JPGs radiométricos da FLIR (com as caixas salvas no FLIR Tools) e gera relatório com alertas:

Módulos (2 ou mais caixas na imagem): alerta se a diferença de temperatura máxima entre caixas passar do limite em °C (padrão 3 °C).
Leituras únicas (1 caixa por imagem): compara imagens do mesmo grupo; alerta se a variação (maior − menor) ÷ menor passar do limite em % (padrão 50%).

Saídas: tabela na tela, Excel e PDF (pela impressão do navegador).

Privacidade

Todo o processamento acontece no navegador de quem usa. Nenhuma imagem é enviada para servidor. A página não carrega nada externo e funciona offline.

Uso

Abra o site, arraste o .zip ou os JPGs e confira os resultados. Os valores conferem com o FLIR Tools (diferença de até 0,05 °C).
